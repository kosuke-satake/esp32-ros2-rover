# レーザーカット

レーザーカッターで作る部品の加工データ．

[English](README.md)

## ここに置くもの

[`../cad/`](../cad) の設計から書き出したファイル．名前は次の形にする．

```
<部品名>-<材料>-<板厚>mm.dxf
```

例：`chassis-base-mdf-3mm.dxf`．レーザーのソフトが SVG の方を扱いやすければ SVG でもよい．

## コミットする前の確認

- 1:1 の縮尺，ミリメートル単位で書き出している．
- 切る線と彫る線だけが残っている．寸法，メモ，補助線は消してある．
- 輪郭が閉じていて，重なった線や二重の線がない（レーザーが2回切ってしまう）．
- 部品名が `../cad/` の設計と一致している．

## コツ

- レーザーは材料を細く焼き飛ばす（カーフ．一般に 0.1〜0.3 mm 程度）．はめ込みにする溝やツメはその分を考える必要がある．設計で補正しているかどうかを PR に書く．
- ある材料をきれいに切れる設定が見つかったら，このファイルに表として追加する（材料，板厚，機械，出力，速度，回数）．
