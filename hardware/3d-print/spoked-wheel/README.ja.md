# Print the spoked wheel

[English](README.md)

最初に小さな軸試験片3種類を印刷し，実際の軸に無理なく合わせて比べる．付属の車輪は nominal の穴寸法を使う．tight / loose が良ければ，元データの穴寸法を変えて車輪を再生成する．`spoked-wheel.stl` を2個，平らな外側面をベッドに付け，突出ハブを上にして印刷する．[取付資料（英語）](print-and-fit.md) と [CAD ガイド](../../cad/spoked-wheel/) を参照．車輪外周と板の横方向の公称隙間は7 mm．形状検証であって実物適合の保証ではない．
