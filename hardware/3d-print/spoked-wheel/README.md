# Print the spoked wheel

[日本語](README.ja.md)

First print the three small axle-fit coupons and compare them on the real shaft without forcing. The supplied wheel uses the nominal coupon fit. If tight/loose fits better, change the source bore and regenerate before printing the full wheel. Print `spoked-wheel.stl` twice, flat outer face on the bed and projecting hub upward. Read [print-and-fit.md](print-and-fit.md) and the [CAD guide](../../cad/spoked-wheel/). Nominal rim/base gap is 7 mm; this is a geometry result, not a physical fit guarantee.
