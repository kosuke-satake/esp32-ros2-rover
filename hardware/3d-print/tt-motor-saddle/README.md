# Print the TT motor saddle

[日本語](README.ja.md)

Print `tt-motor-saddle.stl` four times, after a one-part trial. Print `insert-fit-coupon.stl` to test the actual M3 heat-set inserts. Read [print-and-fit.md](print-and-fit.md) and the [CAD guide](../../cad/tt-motor-saddle/). With the spoked wheels, move the rear saddle to X=-56 within its slot; forward saddle remains X=-10. PETG is a starting choice, not a verified strength specification.
