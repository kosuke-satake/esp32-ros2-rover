# TT motor saddle

[English](README.md)

未製作の試作データを移したもので，確定した設計の変更ではない．単位は mm．生成元は `generate.py`（Python 3.12，仮想環境で `requirements.txt` を導入）．元の書き出し名で無視対象の `generated/` に出力する．確認後，[import-map.csv](../../import-map.csv) を使って対応するリポジトリ内ファイルを一緒に更新する．一覧と検証結果は移行時点の記録であり，形状変更後は再検証する．キャッシュと ZIP はコミットしない．Onshape 文書は作成されていない．STEP は形状を編集できるが元の履歴は含まない．[試作組立資料（英語）](../../prototype-build.md) を参照．

1個で適合を確認してから，同じブラケットを計4個印刷する．[STL と取付資料](../../3d-print/tt-motor-saddle/)．確認用組立は元の後側 X=-55 の配置．後のスポーク車輪案では検証資料の通り X=-56 が必要．
