# Reference components

[日本語](README.ja.md)

Simplified nominal purchased-component and hardware envelopes, retained for layout review only. They are not fabrication files or verified supplier models. Negative coordinate labels are written as `neg`. See [assembly](../robot-assembly/) for context. The servo tabs are simplified separate blocks; their placement is not a verified SG90 drawing. Wheel cylinders here are the original clearance envelopes, not the later printable spoked wheels.
