# 下書き

スケッチ，大まかな構成案，思いつき．まだ決まっていないものを置く場所．手書きの写真，簡単な図，短いメモなど何でもよい．

[English](README.md)

## ルール

- ファイル名は日付と話題で始め，日付順に並ぶようにする（例：`2026-10-01-sensor-layout.jpg`）．
- 写真はコミットする前に縮小する．長い辺が 2000 ピクセル程度あれば十分．
- 下書きは決定事項ではない．決まった設計は [docs/architecture.md](../docs/architecture.md) にある．
- 考えが決まったら，しかるべき場所に書き直す（設計は `docs/`，CAD は `hardware/`）．下書きは記録として残してよい．
