# Drafts

Sketches, rough layouts and early ideas: anything that is not decided yet.
Photos of hand drawings, quick diagrams and short notes are all welcome.

[日本語](README.ja.md)

## Rules

- Start file names with the date and a topic, so they sort in order:
  `2026-10-01-sensor-layout.jpg`.
- Resize photos before committing; about 2000 pixels on the long side is
  enough.
- Drafts are not decisions. The settled design is in
  [docs/architecture.md](../docs/architecture.md).
- When an idea is decided, write it up where it belongs (`docs/` for design,
  `hardware/` for CAD). The draft can stay as a record.
